# Plus Jakarta Sans

Self-hosted variable font (normal, weights 200-800), Latin and Latin Extended
subsets from Google Fonts. Spanish accented letters are included in Latin.
License: SIL Open Font License 1.1, included in OFL-Plus-Jakarta-Sans.txt.

Source: https://github.com/google/fonts/tree/main/ofl/plusjakartasans
Web font distribution: https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@200..800&display=swap

The existing font-sora and font-inter tokens now alias Plus Jakarta Sans so
existing screens adopt the new typography without a bulk component rewrite.
Both WOFF2 files and profile WebP avatars are included in the PWA precache.
